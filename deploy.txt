=== FINDME DEPLOY GUIDE ========================================================
Repo: https://github.com/walterolum/FindMe-lost-and-found-management-system

PRIMARY (free): Render (Docker web service) + Aiven for MySQL + Cloudinary
-> Full step-by-step guide: README.md ("Deploy to Render + Aiven + Cloudinary")
-> Detailed guide + troubleshooting: DEPLOY.md

ALTERNATIVE: PythonAnywhere (free, MySQL built-in) - notes below.

=== 1) RENDER + AIVEN + CLOUDINARY (RECOMMENDED, FREE) =========================

1. Aiven (free MySQL):
   - console.aiven.io -> create MySQL service (free tier)
   - Host / Port 3306 / User avnadmin / Password / Database defaultdb
   - Download the CA certificate, save it in the project root as ca.pem
     (see ca.pem.README). Commit it - it is a public certificate.

2. Initialize the database (from your machine):
     export MYSQL_HOST=your-host.aivencloud.com
     export MYSQL_PORT=3306
     export MYSQL_USER=avnadmin
     export MYSQL_PASSWORD=your-password
     export MYSQL_DB=defaultdb
     export MYSQL_SSL_CA=ca.pem
     python init_db.py
     python create_admin.py     (real admin - never use the demo password)

3. Cloudinary (free images storage - Render's disk is ephemeral):
   - cloudinary.com -> copy Cloud Name / API Key / API Secret

4. Render:
   - Push this repo to GitHub
   - render.com -> New -> Web Service -> connect the repo
     (render.yaml is read automatically: Docker runtime, free plan, /healthz)
   - Dashboard -> Environment, set (declared sync:false in render.yaml):
       SECRET_KEY            strong random (python -c "import secrets; print(secrets.token_hex(32))")
       MYSQL_HOST            your Aiven host
       MYSQL_USER            avnadmin
       MYSQL_PASSWORD        Aiven password
       CLOUDINARY_CLOUD_NAME from Cloudinary
       CLOUDINARY_API_KEY    from Cloudinary
       CLOUDINARY_API_SECRET from Cloudinary
     Preset by render.yaml: MYSQL_DB=defaultdb, MYSQL_SSL_CA=ca.pem,
     MYSQL_PORT=3306, FINDME_ENV=production.
   - Deploy. The app fails loudly at startup if required vars are missing.
   - Verify: https://YOUR-SERVICE.onrender.com/healthz -> "ok"

5. Start command (Dockerfile):
     gunicorn wsgi:app --workers 1 --threads 4 --timeout 120 --bind 0.0.0.0:${PORT:-10000}
   (one worker on purpose: AI-matcher background threads share one process)

Notes:
- Legacy env aliases still work: DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME/
  DB_SSL_CA, and DATABASE_URL=mysql://user:pass@host:3306/db
- Local development needs NO env vars: XAMPP MySQL on localhost +
  local-disk uploads, exactly as before.

=== 2) PYTHONANYWHERE (FREE) - ALTERNATIVE ====================================

1. Sign up at https://www.pythonanywhere.com

2. Bash console:
   git clone https://github.com/walterolum/FindMe-lost-and-found-management-system.git
   cd FindMe-lost-and-found-management-system
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   mkdir -p static/uploads/{avatars,lost,found}

3. Databases tab -> Initialize MySQL:
   CREATE DATABASE yourusername$findme_db;
   USE yourusername$findme_db;
   (then run schema.sql and seed.sql from the Files tab or a console)

4. Web tab -> Add a new web app -> Manual configuration -> Flask:
   - Source code: your clone folder
   - Virtualenv: your venv folder
   - WSGI configuration file: edit it to:

     import sys
     sys.path.insert(0, '/home/yourusername/FindMe-lost-and-found-management-system')
     from wsgi import application

5. Environment variables (Web tab -> Environment variables):
     MYSQL_HOST     localhost
     MYSQL_PORT     3306
     MYSQL_USER     yourusername$findme
     MYSQL_PASSWORD <your mysql password>
     MYSQL_DB       yourusername$findme_db
     SECRET_KEY     <random string>
   (no Cloudinary -> images stay in static/uploads on PythonAnywhere's disk,
    which is persistent there)

6. Reload the web app. Demo login: admin@cavendish.ac.ug / password123

=== OTHER HOSTS ================================================================

All hosts read: Procfile, runtime.txt, render.yaml, Dockerfile, wsgi.py
(pymysql + whitenoise), /health and /healthz.

- Railway (MySQL plugin, fastest paid-adjacent option)
- Docker anywhere: docker-compose up --build -> http://localhost:5000
- Heroku-style: Procfile -> gunicorn wsgi:application

=== QUICK CHECKS ===============================================================

- /healthz  -> "ok"            (liveness, no DB)
- /health   -> {"status":"ok","service":"FindMe"}
- Login/register/report flows work (every POST form carries a csrf_token)
- Admin -> AI Match Review -> "Re-run AI Matching" button regenerates matches
